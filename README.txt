PRIORITY LEXUS VIRGINIA BEACH — L/CERTIFIED LANDING PAGE

FILES
1. L-Certified-Body-Code.html — paste the complete contents into the page body/content editor.
2. assets/lcertified-hero.jpg — upload this image to the website media library.

INSTALLATION
1. Upload lcertified-hero.jpg.
2. Copy the uploaded image URL.
3. Open L-Certified-Body-Code.html and replace this value near the beginning:
   --lc-hero-url: url('assets/lcertified-hero.jpg');
   with the uploaded image URL.
4. Paste the full contents of L-Certified-Body-Code.html into the landing page body.

NOTES
- All CSS is scoped beneath #lc-page to avoid conflicts with the main dealership website.
- All JavaScript is self-contained and runs only inside the landing page.
- Inventory and phone links are already connected.
- The page is responsive and includes reduced-motion and keyboard-accessibility support.
